# BeReal Teardown: Introverted First-Time User Journey Map
A product teardown and user journey map for BeReal, analyzed through the lens of an introverted, first-time user.

<br>

## Overview
- **Objective:** Analyze BeReal's core mechanics, friction points, and retention barriers to evaluate their impact on Monthly Active Users (MAU).
- **Target Persona:** "Denise" — An introverted, first-time user who prefers low-pressure interactions, values privacy, and experiences friction with forced real-time sharing.
- **Key Deliverables:**
  - 4-Part Product Teardown (Core Mechanic, What's Working, What's Broken, MAU Hypothesis)
  - 5-Stage User Journey Matrix (Onboard ➔ Connect ➔ Prompt ➔ Capture ➔ Consume)

<br>

----

## Detailed Stage Breakdown


| Stage Name | User Actions | Introvert Mindset & Feelings | Friction / Pain Points |
| :--- | :--- | :--- | :--- |
| **1. Onboard** | Download app, enter phone number, create username, allow notifications. | Curious but cautious. Wants to explore without committing to posting personal content immediately. | The mandatory phone number and notification requirement feels slightly high-friction. |
| **2. Connect** | Sync contacts, select a few close friends, send requests. | Hesitant and selective. Prefers keeping a small network; resistant to the app's push for "wider sharing." | Heavy contact sync prompts create pressure for users who prefer low-visibility social circles. |
| **3. Prompt** | Receive the simultaneous random notification ("⚠️ Time to BeReal"). | Stressed and reluctant. Feels put on the spot; the 2-minute timer adds performance anxiety. | Artificial urgency conflicts with busy or private schedules, creating an immediate urge to disengage. |
| **4. Capture** | Open camera, take simultaneous front/back photos, tap submit (or post "Late"). | Self-conscious and exposed. Overthinking background and appearance; worried about the "Late" label. | Dual-camera mechanism forces a lack of control; missing the window locks the feed. |
| **5. Consume** | Feed unlocks; view friends' posts, use RealMojis, exit the app. | Relieved, passive observer. Enjoys lurking and authentic connection without obligation to socialize further. | The gated feed (must post to see) creates a significant barrier for users who only want to view content. |

## User Journey Map

| Journey Stage | What does the user do? | What does the user think? | What does the user feel? |
| :--- | :--- | :--- | :--- |
| **Stage 1: Onboard** | Downloads the app, enters phone number, creates username, and grants push notification permissions. | *"I hope this doesn't push me to post right away before I can look around."* | Curious, cautious, slightly hesitant |
| **Stage 2: Connect** | Syncs contacts, searches for specific usernames, and sends select friend requests. | *"I only want to share this with 1–2 trusted close friends, not my whole contact list."* | Selective, guarded, protective of privacy |
| **Stage 3: Prompt** | Receives the daily random push notification ("⚠️ Time to BeReal") with a 2-minute timer countdown. | *"I'm in the middle of working/in public; I wasn't expecting to take a photo right now."* | Stressed, put on the spot, anxious |
| **Stage 4: Capture** | Opens the dual camera, snaps front/back photos simultaneously, and submits (or posts late). | *"My hair/background isn't great, and I hate that it publicizes if I post late."* | Self-conscious, exposed, pressured |
| **Stage 5: Consume** | Unlocks the friends feed, views real-time updates, leaves RealMojis, and exits the app. | *"It's nice seeing what my friends are actually up to, but I'm glad I'm done posting for today."* | Relieved, satisfied, passive observer |
