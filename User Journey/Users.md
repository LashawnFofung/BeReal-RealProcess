# Detailed Stage Breakdown


| Stage Name | User Actions | Introvert Mindset & Feelings | Friction / Pain Points |
| :--- | :--- | :--- | :--- |
| **1. Onboard** | Download app, enter phone number, create username, allow notifications. | Curious but cautious. Wants to explore without committing to posting personal content immediately. | The mandatory phone number and notification requirement feels slightly high-friction. |
| **2. Connect** | Sync contacts, select a few close friends, send requests. | Hesitant and selective. Prefers keeping a small network; resistant to the app's push for "wider sharing." | Heavy contact sync prompts create pressure for users who prefer low-visibility social circles. |
| **3. Prompt** | Receive the simultaneous random notification ("⚠️ Time to BeReal"). | Stressed and reluctant. Feels put on the spot; the 2-minute timer adds performance anxiety. | Artificial urgency conflicts with busy or private schedules, creating an immediate urge to disengage. |
| **4. Capture** | Open camera, take simultaneous front/back photos, tap submit (or post "Late"). | Self-conscious and exposed. Overthinking background and appearance; worried about the "Late" label. | Dual-camera mechanism forces a lack of control; missing the window locks the feed. |
| **5. Consume** | Feed unlocks; view friends' posts, use RealMojis, exit the app. | Relieved, passive observer. Enjoys lurking and authentic connection without obligation to socialize further. | The gated feed (must post to see) creates a significant barrier for users who only want to view content. |
